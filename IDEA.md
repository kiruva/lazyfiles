# lazyfiles

Is a tui file manager to rule them all.
Leans on what Total Commander is to Windows.
Primarily made for the linux community, but should be good to use on MacOS too.

## Tech Stack

- Go or Rust?
- Bubble Tea for Go
- Rust, what alternatives do we have?

## MVP

- Dual Sides
- Intuitive like lazygit
- Copy, Move, Delete, Recursive
- Easy swap back and forth between A and B sides of app.
- Unpack, Pack, Unwrap and copy selected in place
